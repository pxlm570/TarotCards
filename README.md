# 星语塔罗

私人塔罗空间：占卜 · 学习 · 记录 · AI 增强。移动端优先的 Vue 3 + Vite PWA——纯静态、无后端、无账号，所有数据只保存在你自己的设备上（支持 JSON 备份导出/导入）。

**在线访问**：https://pxlm570.github.io/TarotCards/

## 功能

- **占卜**：5 个经典牌阵 + 3 个仪式牌阵（新月 / 满月 / 生日），七步仪式动线（静心→提问→洗牌→抽牌→翻牌→解读），78 牌真随机洗牌，正逆位与代抽开关。
- **学习**：7 章新手课程（图文 / 闪卡间隔重复 / 测验 / 实战），闯关解锁，毕业后全库复习。
- **牌库**：78 牌百科，搜索 / 筛选，皮肤切换（经典韦特 / 复古 Sepia）。
- **记录**：每次占卜自动落库，时间线 / 详情 / 日记编辑 / 删除，Mirror 统计面板。
- **留存**：每日一抽 + 连胜打卡、XP 22 级（大阿尔克那命名）、成就、今日小目标、本命牌。
- **AI 增强**（可选）：深度解读 / 追问 / 我先解点评、问题澄清、学习助教、周期复盘、人格化问候——baseUrl / 模型 / key 全由你在「我的」页自填（任何 OpenAI 兼容端点），不配置则产品 100% 可用。支持配置分享链接 `#import=` 一键导入。
- **体验**：浅色 / 暗夜双主题、睡前大字档、减弱动效、分享卡片、PWA 可安装离线。

## 开发

```bash
npm install
npm run dev      # 开发服务器（手机预览加 -- --host）
npm test         # vitest 单元测试
npm run build    # 生产构建（含 PWA 离线缓存）
```

推送到 `master` 会自动测试、构建并部署到 GitHub Pages。
